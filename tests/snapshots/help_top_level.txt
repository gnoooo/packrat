usage: packrat [-h] [--headers FILE] [--cookies FILE]
               [--cookies-from-browser BROWSER[:PROFILE]] [-v] [--version]
               [--force-new-archive]
               {auth,login,logout,doctor,upgrade,export-metadata,library,download-one,sync,download-manifest,resume,artist,discover} ...

Download music from YouTube Music so you can listen offline. First time? Run
'packrat login', then 'auth' to check it. Then 'sync' downloads your Liked
Songs.

positional arguments:
  {auth,login,logout,doctor,upgrade,export-metadata,library,download-one,sync,download-manifest,resume,artist,discover}
    auth                check that your YouTube Music login works
    login               create your YouTube Music login file
    logout              delete your saved YouTube Music login file
    doctor              check the local setup and optionally the YouTube Music
                        canary
    upgrade             check for or install a newer release
    export-metadata     export track metadata from a saved plan
    library             list your playlists
    download-one        download one song from a link or video ID
    sync                download new songs from Liked Songs or a playlist
    download-manifest (resume)
                        finish or retry downloads from a saved plan
    artist              download an artist's albums and singles
    discover            find new music to download

First-time setup:
  --headers FILE        your YouTube Music login file; create it with `packrat
                        login` (env: PACKRAT_HEADERS; default:
                        ~/.config/packrat/browser.json)
  --cookies FILE        advanced: a cookies.txt file exported from your
                        browser (env: PACKRAT_COOKIES)
  --cookies-from-browser BROWSER[:PROFILE]
                        recommended: read cookies from a browser: firefox,
                        chrome, edge, ...; add :profile for a specific profile
                        (env: PACKRAT_COOKIES_FROM_BROWSER)

Advanced:
  -v, --verbose         show more detail while running (repeat for even more)
  --force-new-archive   start a new download history even if the library has
                        music

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

Common tasks:
  packrat login
  packrat auth
  packrat sync --limit 20
  packrat download-one "https://music.youtube.com/watch?v=..."
  packrat artist "Artist name"
  packrat discover albums

Options like --output, --limit and --dry-run can go before or after the
command. Run 'packrat <command> --help' for details.
