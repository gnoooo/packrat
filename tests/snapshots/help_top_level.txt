usage: ytm-offline [-h] [--headers HEADERS] [--cookies COOKIES]
                   [--cookies-from-browser COOKIES_FROM_BROWSER]
                   [--theme {ocean,sunset,matrix,mono}] [--no-anim]
                   [--no-color] [--ascii]
                   [--palette {auto,custom,fixed,basic}] [-v] [--version]
                   {auth,library,download-one,sync,download-manifest,artist,discover,ui} ...

Download music from your YouTube Music account for offline use.

positional arguments:
  {auth,library,download-one,sync,download-manifest,artist,discover,ui}
    auth                validate ytmusicapi auth
    library             list library playlists
    download-one        download and verify one track by video ID
    sync                sync liked songs or a playlist
    download-manifest   resume/failed downloads from an existing manifest
    artist              download one or more artists' full catalogs
    discover            discover tracks (sections, taste, queues, albums,
                        radio)
    ui                  TUI helpers (demo, glyphs)

options:
  -h, --help            show this help message and exit
  -v, --verbose         verbose logging (-v = debug, -vv = yt-dlp verbose)
  --version             show program's version number and exit

Authentication:
  --headers HEADERS     path to ytmusicapi browser-headers JSON file (env:
                        YTM_HEADERS)
  --cookies COOKIES     path to Netscape cookies.txt for yt-dlp (env:
                        YTM_COOKIES)
  --cookies-from-browser COOKIES_FROM_BROWSER
                        browser/profile for yt-dlp, e.g. firefox[:profile]
                        (env: YTM_COOKIES_FROM_BROWSER)

Display:
  --theme {ocean,sunset,matrix,mono}
                        TUI color theme (default: ocean)
  --no-anim             disable TUI animations (env: YTM_TUI_ANIM=0)
  --no-color            disable TUI colors (env: NO_COLOR)
  --ascii               use ASCII progress bars in the TUI
  --palette {auto,custom,fixed,basic}
                        color tier (auto/custom/fixed/basic) (default: auto)
