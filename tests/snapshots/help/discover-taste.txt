usage: packrat discover taste [-h] [--headers FILE] [--output DIR]
                              [--archive FILE] [--max-size SIZE]
                              [--min-duration SECONDS]
                              [--max-duration SECONDS] [--quota N] [--deep N]
                              [--adjacent N] [--radio N] [--external N]
                              [--tag N] [--per-album N] [--per-artist N]
                              [--family-cap N] [--skip-previous]

Common options:
  --output, -o DIR      folder where songs are saved (env: PACKRAT_OUTPUT;
                        default: ~/Music/PackratMidden)
  --quota N             how many songs per category (overrides the defaults
                        below)
  --skip-previous       skip songs already in the last discover plan

First-time setup:
  --headers FILE        your YouTube Music login file; create it with `packrat
                        login` (env: PACKRAT_HEADERS; default:
                        ~/.config/packrat/browser.json)

Advanced:
  --archive FILE        download history file, so finished songs are not
                        downloaded again (env: PACKRAT_ARCHIVE; default:
                        ~/.config/packrat/archive)
  --max-size SIZE       skip songs bigger than SIZE (example: 3GB)
  --min-duration SECONDS
                        ignore songs shorter than this many seconds (default:
                        90)
  --max-duration SECONDS
                        ignore songs longer than this many seconds (default:
                        540)
  --deep, --quota-deep N
                        songs from deep in an artist's catalog (default: 12)
  --adjacent, --quota-adjacent N
                        songs by similar artists (default: 10)
  --radio, --quota-radio N
                        songs from radio stations (default: 10)
  --external, --quota-external N
                        songs from Last.fm recommendations, needs
                        LASTFM_API_KEY (default: 5)
  --tag, --quota-tag N  songs found by genre tag (default: 5)
  --per-album N         how many songs per album (default: 2)
  --per-artist N        how many songs per artist (default: 3)
  --family-cap N        limit songs per artist family, 0 = no limit (default:
                        0)

options:
  -h, --help            show this help message and exit
