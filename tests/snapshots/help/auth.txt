usage: packrat auth [-h] [--headers FILE]

Check that your YouTube Music login works. If you have no login file yet, run
'packrat login' first.

First-time setup:
  --headers FILE  your YouTube Music login file; create it with `packrat
                  login` (env: PACKRAT_HEADERS; default:
                  ~/.config/packrat/browser.json)

options:
  -h, --help      show this help message and exit
