usage: packrat library [-h] [--headers FILE] [--top N]

List your playlists. To download one, use its ID with 'sync --source
playlist:<ID>'.

Common options:
  --top N         how many playlists to list (default: 25)

First-time setup:
  --headers FILE  your YouTube Music login file; create it with `packrat
                  login` (env: PACKRAT_HEADERS; default:
                  ~/.config/packrat/browser.json)

options:
  -h, --help      show this help message and exit
